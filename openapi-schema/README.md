Контракт Rick and Morty API: Retrofit-интерфейсы в `api`, JSON-модели в `model`.

Модуль соответствует границе `:openapi-schema` в skinepic-android. Сейчас контракт
описан вручную: проверенной OpenAPI-спецификации Rick and Morty в проекте нет.
Доменные модели и преобразование ответов находятся в data/domain модулях фич.
